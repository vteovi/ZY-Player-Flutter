## v1.34.0 设置开关切换「收藏历史合并 / 分开」（dev，未推送）
- 用户：「在设置里弄一个开关，切换这两种页面模式，一种是合并的，一种是分开的。就是保留之前那种收藏和历史合并的模式和现在这种分开的」→ 追加：「还有那种收藏历史合并的导航栏，就叫**我的**」。
- 实现：
  - `AppConfig` 新增 `mergeRecords`（bool，**默认 false = 分开**，保持 1.33.0 现状，老用户升级无感）+ `AppState.setMergeRecords()`。
  - 新增 `lib/pages/records_page.dart`（合并页 `RecordsPage`）：AppBar 标题 **「我的」** + TabBar（`Tab(text: '收藏 N')` / `'历史记录 N'`，条数沿用老版写法直接拼在文字里）+ TabBarView 两个 `RecordGrid`；支持 `initialTab`。
  - `main_page.dart` 重写导航：**用「逻辑槽位」而不是物理下标** —— `_slot` 取值 0=首页 1=收藏 2=历史 3=设置，`_slotOf()/_indexOf()` 双向映射。
    - 分开：`[首页, 收藏, 历史, 设置]`，槽位 == 下标
    - 合并：`[首页, 我的, 设置]`，槽位 1 和 2 都落到下标 1（合并页），槽位 3 → 下标 2
    - **为什么不用物理下标**：拨开关时停在「历史」的用户会被弹到别处/越界；槽位方案让语义保持，`_indexOf(0..)` 永远合法。
    - `_pages()` / `_railDestinations()` / `_barItems()` 全部按 `merge` 生成；`build` 里 `context.select<AppState,bool>((s) => s.config.mergeRecords)` 触发重建。
    - 合并页初始化 `RecordsPage(initialTab: _slot == 2 ? 1 : 0)` —— 从历史槽位切过来直接落历史分栏。**State 的 `late final TabController` 只初始化一次，所以后续 rebuild 改 initialTab 不会重置用户当前分栏。**
    - 「我的」图标用 `Icons.account_circle(_outlined)`。
  - `me_page.dart`：开关放在「显示视图切换按钮」下面；「播放记录」入口按模式分流（合并 → `RecordsPage(initialTab: 1)`，分开 → `HistoryPage()`）。
  - `star_page.dart` 顶部注释改成「只在合并关闭时出现」，避免误导后人。
- 注意：`bottomNavigationBar` 在 3 项 / 4 项之间切换，靠 `main.dart` 的 `type: fixed` 保持不变形（之前就写死了）。
- 版本 1.33.0+227 → **1.34.0+228**（feat 升 MINOR）。更新记录已加。
