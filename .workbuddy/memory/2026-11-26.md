## v1.43.0 播放页「画面」按钮合并

- 用户反馈：播放页「画面比例」和「画面大小」看着像同一个功能，要求合并成一个按钮。
- 事实确认：两者确实是两步——比例决定内容形状（`shaped` 用 `BoxFit.fill` 填进目标形状），大小决定形状怎么塞进 `_stageAreaSize`。`_stageAreaSize` 只在 cover/fill 时占满高度，所以「自适应 + 适配屏幕」时两者观感一致，用户误判很正常。
- 改法（`lib/pages/play_page.dart`）：
  - `_aspectPanelOpen` + `_scalePanelOpen` → 单个 `_screenPanelOpen`；`_buildAspectPanel` + `_buildScalePanel` → `_buildScreenPanel()`（Column 内两段 `_buildPanel`，第一段 `bottom: 6` 收窄间距）。
  - `_buildPanel` 新增 `double bottom = 10` 参数。
  - 按钮只剩一个：icon `aspect_ratio_rounded`，label 固定「画面」，`active` = 面板开 || 比例非自适应 || 交换宽高 || 填充方式非默认（同倍速按钮常亮逻辑）。
  - 底部按钮行竖屏多集时从 8 个降到 7 个。
- 静态校验：0 error / 0 warning / 31 info（基线）。**未跑 `dart format`**。
- 版本 1.43.0+242（pubspec + local.properties），`更新记录.MD` 已加条目。
- 提交 `562b6078`，仅本地，**未 push**。
- 遗留风险：合并面板比原「比例」面板高约 40px，超小窗口（桌面 < 300 高）理论上仍可能 RenderFlex 溢出，属旧有问题量级，未处理。
