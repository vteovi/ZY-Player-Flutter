## 又一个 push 拦路虎：全局 gitconfig 的 url.insteadOf（已删）
- 现象：`git push origin dev` 报 `remote: No anonymous write access.` + `fatal: Authentication failed for 'https://gh-proxy.com/https://github.com/vteovi/ZY-Player-Flutter.git/'` —— 注意 URL 里凭空多了 gh-proxy 前缀。
- 根因：`~/.gitconfig`（2026-11-16 15:51 被改过）里有
  `[url "https://gh-proxy.com/https://github.com/"] insteadof = https://github.com/`，把所有 github 地址改写成 gh-proxy 镜像；该镜像是**只读加速代理**，不接写入，所以 push 必失败。`git remote -v` 输出的是改写后的 URL，可作为第一眼判据。
- 处理：删掉 `[url ...]` 与配套的 `[credential "https://gh-proxy.com"]`（gh-proxy 只用于读，删掉不影响 clone/fetch 走直连）。删完 push 一次通过。
- 已补进 MEMORY.md 第 3 条。**以后见到 403 / 认证失败先看 remote URL 有没有被改写**。
