## http_service.dart 三项兼容性修复（2026-10-01）
背景：用户反馈「有的源加载不了」。修复**只改 `lib/services/http_service.dart` 一个文件**。

1. **请求方式**：新增 `_fetch()` = **GET 优先，仅在响应 4xx 时回退 POST**。
   原 `_post()`（所有接口统一 POST，对齐 uni-app uni-ajax）已删除。
   - 触发原因：`cj.lziapi.com`（量子资源）只放行 GET，POST 直接 403。
   - ⚠️ **关键设计**：DNS / 连接 / 超时这类**网络层失败不重试** ——
     换方法一样会失败，无脑重试会让一个死站白等 2×15s = 30s。
2. **解析方式**：不再由 `site.isJson`（即 `type` 字段）决定解析器，
   改为 `_parse()` 按**响应首字符自证**：`{`/`[`→JSON，`<`→XML，认不出则两种各试一次。
   结果装进新类 `_Payload{json, xmlDoc}`。
   - 触发原因：`淘片资源` 标注 `xml` 但实际返回 JSON。
   - 五个接口（fetchList / search / fetchDetail / fetchPage / fetchClasses）
     全部改走统一的 `_load()`；helper：`_videosFrom/_videosFromJson/_videosFromXml`、
     `_pageFromJson/_pageFromXml`、`_detailFromJson/_detailFromXml`、
     `_classesFromJson/_classesFromXml`。
   - `fetchClasses` 先试 `?ac=list` 再试裸 api，**网络失败立即返回**不试第二个地址。
3. **响应解码**：新增 `_decode()` —— 响应头没 `charset` 时按 **UTF-8** 解
   （`http` 包的 `res.body` 默认 latin1，中文站必乱码）。用
   `res.bodyBytes` + `utf8.decode(allowMalformed: true)`。
   ⚠️ GBK/GB2312 站仍不支持（`dart:convert` 无该 codec，`Encoding.getByName('gbk')` 返回 null），
   退回 UTF-8，与改前一样是乱码、不会更差。

⚠️ **踩坑**：`_Payload` 的字段一开始命名为 `xml`，**遮蔽了 `import 'package:xml/xml.dart' as xml`
的前缀**，analyzer 报 `PREFIX_SHADOWED_BY_LOCAL_DECLARATION`。改名 `xmlDoc` 解决。
→ **Dart 里不要用 import 前缀同名做字段名或局部变量名。**

- `Site.isJson` 改后已无引用，作为 public getter 保留（不会触发 unused 警告）。
- 静态检查：25 文件 `0 errors / 0 warnings / 0 lints`。
