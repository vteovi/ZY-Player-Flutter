## 搜索页返回不再自动弹键盘（1.9.20+174）
- 根因：`_doSearch` / `_resetToHistory` 用 `FocusScope.of(context).unfocus()` 只把焦点上移一级，TextField 仍是路由的"最后聚焦节点"，从详情页 `pop` 回来时 Flutter 恢复该节点 → 键盘又弹。
- 改 `lib/pages/search_page.dart`：三处都改成对搜索框自身 `_focusNode.unfocus()`；`_openDetail` 在 push 详情前先 unfocus，并在 `push().then` 返回后兜底再收一次。首次进入页面保留 `initState` 的 `requestFocus` 弹键盘（用户期望），仅取消"返回后的自动聚焦"。
- 版本 1.9.19+173 → 1.9.20+174（四处同步）。静态检查无 error/warning，仅 5 条既有 info（search_page:137 的 curly_braces 是老问题）。已提交 `1f52349e`。

## 局域网设备同步（1.10.0+175，新功能）
- 新增设置页「设备同步」入口（lib/pages/sync_page.dart）。两种角色：开启共享（发送端，起 HttpServer 9527 暴露选定库原始数据 + 周期组播 239.255.100.100:19528 广播自身）/ 连接同步（接收端，监听组播自动发现或手动输入 IP 兜底，拉取并 upsert 合并）。
- 同步范围可勾选：视频源 / App 配置 / 收藏 / 历史播放记录（按用户要求全量）。
- 实现零额外依赖，全基于 dart:io（RawDatagramSocket 组播 + HttpServer）。Android 无需额外权限（INTERNET + usesCleartextTraffic 已具备）；iOS 补 NSLocalNetworkUsageDescription。
- 底层：ZyDatabase 新增 importRaw（upsert 合并）；AppState 新增 exportDbs/importDbs（直接读写存储层 JSON，不关心模型字段）。
- 版本 1.9.20+174 → 1.10.0+175（新功能 MINOR 升）。静态检查无 error/warning，仅 7 条既有 info（sync_page 的 use_build_context_synchronously 已用 mounted 防护，属 info 级）。已提交 `e38401e2`。

## 设备同步：保留来源排序（1.10.2+177）
- 根因：视频源/收藏/历史的展示顺序由 ZyDatabase 的 key 列表（ZY-{db}-DB）决定。exportDbs 经 getAll 已按序导出，但 importRaw 经 put 把新增 key 追加到末尾，接收端丢掉发送端排序，同步源堆在后面。
- 改 lib/services/zy_database.dart：importRaw 写入后新增 _reorderKeysAfterImport，把 key 列表重排为「来源顺序在前（保持来源相对顺序）、接收端独有在后（保持原相对顺序）」。对所有同步库通用（源/收藏/历史的手动排序/置顶/检测后重排结果都会带过来）。
- 版本 1.10.1+176 → 1.10.2+177（修 Bug，PATCH 升）。静态检查无 error/warning，仅 7 条既有 info。已提交 `a9504a01`。README 同步说明补充「排序也会一并同步」。
