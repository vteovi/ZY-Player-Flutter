## v1.25.0 导航栏改造（commit `830e1dbe`，dev，未构建）
- 需求：导航栏选中态太弱；把「历史」提到导航栏（收藏右边）；收藏/历史/设置支持左右滑动。
- 改动：
  - `main_page.dart`：`BottomNavigationBar` → M3 **`NavigationBar`**，四项 首页/收藏/历史/设置；`_destinations` 为 `static const List<NavigationDestination>`，Rail 从同一份 map 出来避免两边不一致。
  - 选中态：胶囊 `indicatorColor`（深色 `0xFF12314F` / 浅色 `0xFFE3F0FC`）+ 选中图标放大 25/22 + 实心图标 + 文字 w600。**纯黑主题下原来的「白 vs 白 70%」几乎看不出区别**，这是「不够明显」的根因。
  - `main.dart`：删 `bottomNavigationBarTheme`，换 `navigationBarTheme`（backgroundColor / height 66 / iconTheme / labelTextStyle 用 `WidgetStateProperty.resolveWith`）。
  - `NavigationRail` 同步加 `indicatorColor` + `selected/unselectedIconTheme` + 选中文字 w600。
  - 滑动：body 用 `IndexedStack(index: _index == 0 ? 0 : 1)` 装 [FilmPage, PageView(收藏, 历史, 设置)]。**首页不进 PageView** —— 它内部已有分类 `TabBarView`，会抢横向手势。点导航用 `jumpToPage`（postFrameCallback，避免 IndexedStack 刚切换那一帧没 viewport）；滑动用 `onPageChanged` 反向同步 `_index`。
  - `star_page.dart`：加 `only` 参数（0=单栏收藏 / 1=单栏历史 / null=原双分栏），`TabController` 改可空、仅双栏模式创建。单栏没有 TabBarView，横滑才能交给外层 PageView。
  - `me_page.dart`：「播放记录」入口 `StarPage(initialTab:1)` → `StarPage(only:1)`。
  - `_KeepAlive`（AutomaticKeepAliveClientMixin）包住 PageView 的三个子页，滑走再回来不重建。
