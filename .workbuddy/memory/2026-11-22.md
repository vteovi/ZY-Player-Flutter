## v1.25.1 修复滑动切换掉帧（commit `29413090`，dev，未推送）
- 用户反馈：收藏/历史/设置左右滑动切页「有些卡顿掉帧」。
- 根因（三条，都是实测代码路径确认）：
  1. `_onTap` / `_onPageChanged` 里调 `AppState.refresh()` —— 重读 site/setting/star/history **4 张表**，`loadSetting` 还会走一次原生 `SystemControl.setForceSoftwareDecode` 通道，且 4 个 load 各 notify 一次 + refresh 末尾再来一次 = **5 次 notifyListeners**，正好压在翻页动画那几帧。
  2. `IndexedStack` 只「不绘制」未选中子树，**Ticker 仍在跑**：首页 `VideoGridSkeleton` 是 `repeat(reverse: true)` 的呼吸动画、`LinearProgressIndicator` 是 indeterminate，停在收藏页时仍每帧驱动。
  3. `StarPage` / `MePage` 用 `context.watch<AppState>()`，任何 notify（含播放页每 10s 写一次进度 `updateHistory`）都重建整页（MePage 990 行 ListView 含文件选择器）。
- 改动：
  - `main_page.dart`：删掉切页时的 `refresh()`；首页包 `TickerMode(enabled: _index == 0)` + `RepaintBoundary`；PageView 三页各加 `RepaintBoundary`；顺手删掉不再用的 provider / app_state import。
  - `star_page.dart`：`watch` → `context.select((AppState s) => s.stars / s.histories)`（单栏按 only 选一份），列表换了才重建。
  - `me_page.dart`：`watch<AppState>()` → `select((s) => s.config)`，`appState.config.x` 全部改 `config.x`；`_buildExternalPlayerTile` 改 select `externalPlayerPath`。
- 版本 fix → PATCH：1.25.0+212 → **1.25.1+213**。已提交 dev，**未推送、未构建**。
