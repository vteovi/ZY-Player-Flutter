# 2026-10-31

## CI 增加 Windows 桌面版构建（09:40）
用户问「同时编译 x86_64 那种 PC 版」，澄清后是要 **Windows 版**（x86_64 APK 是安卓 x86/模拟器，装不到 Windows）。
- `.github/workflows/build-apk.yml`：workflow 改名 `Build APK + Windows`，**新增 `build-windows` job**（`runs-on: windows-2022` 固定版本，避开 latest→2025 迁移）：checkout → flutter-action → `flutter build windows --release` → `Compress-Archive` 打成 `dist/ZY-Player-v<版本>-windows-x64.zip` → upload-artifact → tag 时 `gh release upload`。
- 两个 job **并行且互不依赖**（一个红不拖累另一个）；新增的 API 时间内耗时不叠加。
- **Release 竞态**：两个 job 都会往同一 tag 传资产，原来「view→create/upload 二选一」有 TOCTOU（两边同时发现不存在，第二个 create 失败）。改成统一 `if ! gh release view; then gh release create ... || true; fi` 再 `gh release upload --clobber`，APK job 也一并改。
- fvp 的 `cmake/deps.cmake` 在**配置阶段 file(DOWNLOAD) 拉 mdk-sdk**（windows/CMakeLists 里 `fvp_setup_deps()`），所以 CI 首次 Windows 构建会多花几分钟下载；本机因缓存过所以只要 79.7s（见 tools/build_windows_log.txt）。
- README 补「Windows 桌面版怎么出」+ CI 两 job 说明 + 明确 **x86_64 APK ≠ PC 版**；强调 Windows 必须整目录分发（exe + dll + data），一律发 zip。
- CI/README 改动不进 APK，**未升版本号**（仍是 1.19.0+197）。

## Windows 版设备同步「8 秒超时」实测定位（10:00）
用户报 Windows 版同步总提示 `SocketException: HTTP connection timed out after 0:00:08, host: 192.168.31.72, port: 9527`。
**实测结论：Windows 侧与网络侧全部正常，问题在手机端当时的响应状态。**
- 本机 `192.168.31.81`（WLAN，SSID K5-101，Private 配置文件），路由到 `.72` 直走 WLAN，无虚拟网卡抢路由。
- 扫 192.168.31.0/24 的 9527：**`.72` 端口是开的**（ARP Reachable，MAC D8-93-D4-0A-EF-CD）。
- `curl --noproxy '*' http://192.168.31.72:9527/sync` → **200，0.125s，550KB**，4 个库齐全。
- 用与 App 完全相同的 Dart `HttpClient`（复刻 SyncClient.fetch）跑：默认代理策略 343ms / 强制 DIRECT 184ms / 再测 166ms，**全部 OK**。→ 排除代码、代理、超时逻辑。
- 防火墙：**没有为 zy_player.exe 建过任何规则**，出站默认允许，只有 Windows Defender，无第三方安全软件。→ 排除 Windows 拦截。
- `Test-NetConnection` 报 TcpTestSucceeded=False 但 ping 也不通 —— **不要信它**：它先做 ICMP 就卡住，而手机会静默丢弃 ping。用 TcpClient/curl 才是准的。
- 根因判断：`HTTP connection timed out` 是**连接阶段**超时（SYN 无响应），不是 refused。手机进程被杀会 RST→refused；只有**息屏后 Wi-Fi 进入省电/断网**或 Doze 限制网络才会把 SYN 直接丢掉。用户坐电脑前操作时手机必然是息屏的，故「总是」。
- 代码改进（1.19.1+198）：
  - `SyncClient.fetch` timeout 8s → **12s**，连接类失败（SocketException/TimeoutException/HttpException）自动**补试一次**（间隔 700ms），给手机唤醒时间。
  - 新增 `SyncClient.ping()`（Socket.connect 测端口，返回 ms）+ `SyncClient.describeError()` 把异常翻成人话（超时/refused/unreachable/解析失败分档，超时档直接列出三条该查的东西）。
  - 新增 `SyncException`（已翻译的可预期失败，不参与重试）。
  - `sync_page`：加「测试连接」按钮（只测连通、不导数据）+ `_resultBox`（状态图标 + 自动换行），`_doSync` catch 走 describeError。
- 版本 1.19.0+197 → **1.19.1+198**；`update.json` 更新到 1.19.0/197（之前停在 1.18.4/196，已装 1.19.0 的用户收不到提示）。
