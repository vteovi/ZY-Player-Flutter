## 画面比例支持自定义（commit 713383b，1.24.0+208，dev）
- 需求：「视频播放比例切换里加一个自定义，由用户指定画面比例」。
- 实现分层：
  - `utils/player_options.dart`：`PlayerAspects.customKey='custom'` + `parseRatio`（支持 `21:9` / `2.35:1` / `2.35`，全角冒号也认）+ `parseParts`（给对话框回填宽高）+ `isValidRatio`（0.2~5.0）+ `labelOf`（仅比例值缺原文时兜底反推）。`byKey` 增加 `customRatio` / `customLabel` 两个可选参数。
  - `AppConfig.playerCustomAspect`（String）随 `playerAspect='custom'` 一起持久化；`AppState.setPlayerCustomAspect` 写库。
  - 播放页：比例面板在预设 chip 后加「自定义…」chip，选中后显示「自定义 21:9」；弹窗两个输入框填宽/高，校验 >0 且比例 1:5~5:1，确定后存原文。
- ⚠️ 关键取舍：**标签必须保留用户原文，不能按比例反推**。最初用 `labelOf(ratio)` 反推最简比，21:9（2.3333）会被化成 7:3（h=3 时 w=7 命中容差），用户填的和看到的对不上。改成对话框直接回传 `"21:9"` 这种归一化原文，`custom(ratio, label: raw)` 使用；重启时从 `playerCustomAspect` 读回原文，只有原文缺失才走 `labelOf` 兜底。
- `_applyCustomAspect` 里先 `setPlayerCustomAspect(raw)` 再 `setPlayerAspect('custom')`（两次写库，配置最终一致）；全屏中应用会调 `_applyFullscreenOrientation()` 同步横竖方向。
- 对话框用 `showDialog<String>` + `StatefulBuilder` 管理错误提示；控制器在 `await` 之后 dispose，并 `if (!mounted || raw == null) return`。
- 版本 feat → MINOR：1.23.0+207 → **1.24.0+208**（pubspec + local.properties），更新记录.MD 加 v1.24.0。
