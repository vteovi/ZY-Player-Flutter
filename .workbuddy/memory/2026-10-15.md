## 修复双击 build_apk.bat 构建失败
用户双击 `tools/build_apk.bat` 构建报错（BUILD_FAILED）。排查日志发现两类根因，均已修复：
- **`No Android SDK found` / `java.exe not found`**：`ANDROID_HOME` 与 `JAVA_HOME` 当初只在我搭建会话里临时 set，未持久化；用户双击时进程环境里没有，Flutter 找不到 SDK/JDK。现已把 `ANDROID_HOME=C:\Android\Sdk`、`JAVA_HOME=C:\Java\jdk-17` 持久化（User+Machine），并在 `build_apk.bat` 开头显式 `set` 兜底。Flutter 3.32 走 `JAVA_HOME` 系统 JDK 17（缓存 `bin/cache/jdk` 缺失，因 googleapis 被掐）。`flutter doctor -v` 验证：SDK/Java 均正确识别。
- **`Building with plugins requires symlink support`**：本机 `SeCreateSymbolicLinkPrivilege` 默认关闭。已在 `build_apk.bat` 加自动提权（未开开发者模式时 `Start-Process -Verb RunAs` 重跑自身，确认一次 UAC）；并把注册表 `AllowDevelopmentWithoutDevLicense` 置 1（开开发者模式，重启后双击可静默构建）。
- `android/local.properties` 本身已有 `sdk.dir=C:\Android\Sdk`；licenses 已接受。改动仅 `tools/build_apk.bat`（仓库内，已提交）。
